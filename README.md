# Death's Door Poptracker pack

This is a pack intended to be used with Poptracker (https://github.com/black-sliver/PopTracker) to track your progress in the Death's Door archipelago randomizer mod (https://github.com/roseasromeo/DeathsDoorAPWorld?tab=readme-ov-file#deathsdoorarchipelago-apworld-for-deaths-door). It is currently in a "usable, but incomplete" phase. The logic is incomplete and may be broken, and the item panel is massive for debugging purposes.

## Installation

Just download the latest build or source and put in your packs folder (zipped).
